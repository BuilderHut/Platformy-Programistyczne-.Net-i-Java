# Laboratorium 6 - Edytor obrazów JavaFX

Katalog zawiera aplikację desktopową JavaFX do prostej obróbki obrazów JPG.

Główny projekt znajduje się w katalogu:

```text
image-editor/
```

Szczegółowy opis, wymagania i komendy uruchomieniowe są dostępne w pliku:

```text
image-editor/README.md
```

## Skrót

- język: Java,
- interfejs: JavaFX,
- narzędzie budowania: Maven,
- główna klasa aplikacji: `pl.pwr.Main`,
- zakres: wczytywanie obrazów, negatyw, progowanie, konturowanie, obrót, skalowanie i zapis wyniku.
