# Laboratorium 7 - JHipster

Katalog zawiera aplikację bazodanową wygenerowaną w JHipster i rozszerzoną o własny model danych wypożyczalni samochodów.

Główny projekt znajduje się w katalogu:

```text
car-rental-app/
```

Szczegółowy opis, wymagania i komendy uruchomieniowe są dostępne w pliku:

```text
car-rental-app/README.md
```

Zrzuty ekranu dokumentujące wykonanie laboratorium znajdują się w katalogu:

```text
screenshots/
```

## Skrót

- generator: JHipster 9.1.0,
- backend: Spring Boot WebFlux,
- frontend: Angular,
- baza danych: MySQL,
- wyszukiwanie: Elasticsearch,
- wykonane zadania: Zadanie 1 i Zadanie 2 z instrukcji laboratoryjnej.
